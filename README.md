# linguaviva.art

This repository holds ONLY the public website for Lingua Viva (served by GitHub Pages
from the root of `main`, custom domain `linguaviva.art`) and the public release assets
(installers) under Releases.

There is no application code here. The application lives in a private repository;
its release pipeline publishes installers into this repository's Releases.

Spec: `SPEC_EXTERNAL_RESEARCH_PERMANENT_ARCHITECTURE_2026-09-08` §4 (Phase 1), mirroring the
Mission Canvas pattern (private code repo + public site/assets repo).
